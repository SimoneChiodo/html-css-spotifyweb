# Spotify Clone

## Descrizione

Il progetto mira a simulare la homepage di Spotify, riproducendone fedelmente l'aspetto grafico e la disposizione dei contenuti. L'interfaccia è completamente responsive e si adatta a diverse risoluzioni e dispositivi, mantenendo coerenza visiva e funzionalità. L'obiettivo è ricreare l'esperienza di navigazione tipica della piattaforma, con particolare attenzione alla struttura della pagina, alla disposizione degli elementi e all'estetica generale.
